# Current Features
- Scheduled Messages (with webhooks & recurring schedules)
- Temp voice channels
- Giveaways with reactions, requirements, DM/ping options & rerolls
- Polls with a unique and live interface
- Birthdays (announcements, countdowns & custom messages)
- Reminders (time-based & reaction reminders)
- Autoroles & fully customizable reaction roles
- Tags
- Media Channels
- Timezone converting
- Community themes & prefix customization
- Multi-language support
